## 💗 About

**Arcade Hub** is a React single-page application developed as my final project for Web Game Design (IT3049C). The goal was to create a central hub where users could jump into several classic browser games while maintaining a consistent experience through shared settings, themes, and navigation.

---

## ✨ Features

- Multiple classic web-based games
- Shared Lobby with customizable player settings
- Responsive React interface
- Global theme management using React Context
- Automated end-to-end testing with Playwright
- Deployed with GitHub Pages & GitHub Actions

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/nasolily/arcade-hub
cd arcade-hub
```

### Install dependencies

```bash
npm install
```

### Install Playwright

```bash
npx playwright install
```

### Run locally

```bash
npm run dev
```

### Run tests

```bash
npx playwright test
```

### Deploy

```bash
npm run build
npm run deploy
```

## 🌱 What I Learned

- Separating game logic from UI components made the project much easier to maintain.
- React Context helps to manage shared settings across multiple pages.
- Organizing larger React applications requires thoughtful folder structure from the beginning.
- User testing helped me catch UI inconsistencies that I had overlooked.

---

## 🌸 Project Structure

```
src/
├── components/   # Game UI components
├── context/      # Global state & themes
├── logic/        # Game engines & helper functions
└── pages/        # Main pages & routing
```
